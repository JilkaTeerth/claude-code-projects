# Trip and weekend guides

Research pages for friends, built with Claude doing the web research.

- **Spring break board**: compares destinations on fun for the money, an itemised cost per person, what a day there actually looks like, safety, and a booking timeline, with sources and photo credits.
- **Lancaster weekend guide**: cheap views around Lancaster County for a long weekend.

## What's in `src/`

The spring break board page (its photos folder is left out) and the weekend guide notes.
