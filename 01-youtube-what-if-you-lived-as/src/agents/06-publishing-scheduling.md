# Agent 06, Publishing & Scheduling

## Mission
Publish the finished video correctly and on the channel's cadence.

## Inputs
- Final MP4 + thumbnail PNG (from Agent 05)
- `03_SEO.md`
- `templates/PUBLISHING_CHECKLIST.md`

## Steps
1. Upload MP4. Paste title, description, tags from `03_SEO.md`.
2. Set custom thumbnail PNG.
3. Add chapters (already in description), end screen, and a card to the previous episode.
4. Set audience ("not made for kids" unless policy says otherwise), language, category = Education or Entertainment.
5. Add to the format playlist ("What If You Lived As...").
6. Pin the comment from `03_SEO.md`.
7. Schedule at the channel's best slot (default: publish window chosen by Agent 07; if none yet, weekday 15:00 to 18:00 local to core audience).
8. Record publish datetime in `STATUS.md` so Agent 07 knows the 48h / 7d windows.

## Cadence
- Default 2 to 3 videos/week. Never publish an unapproved script.

## Output
Published/scheduled video URL + publish datetime → `STATUS.md`.
