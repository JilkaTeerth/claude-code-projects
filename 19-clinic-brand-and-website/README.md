# Clinic brand system and website guidance (client work, anonymised)

Internship work for a microbiome clinic in Pune.

- **A 30 template Figma component library** for Instagram, plus an original pattern system.
- **A design guidance document for an external web agency** building the clinic's site, including a competitor review with screenshots.
- **A client handover package**: 33 files, 7 documents written, including a 9 page guide that explains the Figma system to someone with no design experience. It has a copy paste AI prompt designed to make the model stop and report instead of silently shrinking text to fit.

## How it was checked

- The brand rule "no dashes" was enforced in code: the PDF build fails on any dash. Zero dashes across 7 PDFs and 7 text files.
- Every PDF page was rendered to PNG and looked at, which caught a checkbox glyph rendering as a filled square and a table column collapsed to one word per line.
- Software pricing behind the main recommendation was fetched live rather than recalled.

No code or assets here: they belong to the client.
