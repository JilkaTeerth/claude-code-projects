# Party invite

A cinematic, mobile first web invite for a reunion dinner with about 16 friends.

Direction came from an LLM council: treat the group photo like a movie poster and never darken the faces, only the bottom where the text sits. The palette is pulled from the fire and dusk sky in the photo, so the type looks lit by the same fire.

Features: a live rising ember particle system from the fireplaces, a teal orange colour grade, cursor and tilt parallax, film grain, vignette, and a title that ignites word by word.

## What's in `src/`

`index.html`. The group photo is left out for privacy, so the page needs any landscape photo saved as `uswd.jpg` next to it.
